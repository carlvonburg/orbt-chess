Download

ORBT Chess is free on every platform: no subscription, no ads, no account. To keep your repertoires on several devices, choose iCloud Drive (Apple devices only), Dropbox or Google Drive in Settings › Sync.

iPhone, iPad and Mac

iOS 26, iPadOS 26 or macOS 26

One download for all three, with your repertoires in iCloud Drive.

Android

Android 10 or later, phones and tablets

Get it onGoogle Play

Windows

Windows 10 or 11, x64

Get it fromMicrosoft Store Download the installer (.msi)

The Store version updates itself. The installer from GitHub doesn't, and Windows asks once before running it, since it isn't signed: choose More info › Run anyway.

Linux

x64, Debian, Ubuntu and other distributions that install .deb packages

Download the package (.deb)

Install it from the folder you downloaded it to:

sudo apt install ./orbt-chess_amd64.deb

It doesn't update itself: download the new package when there is a release.

Repertoire files

On Windows and Linux your repertoires are PGN files in the ORBT Chess folder in your home folder, where you can also drop in PGNs from other apps. On Apple devices they're in iCloud Drive › ORBT Chess; on Android they're kept by the app.

Other downloads

Every release, its checksums (SHA-256) and its source code are on GitHub Releases; to hear about new ones, watch the repository's releases. You can also build it yourself.
